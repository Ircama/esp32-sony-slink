Install the S-Link firmware

ESP32 Sony S-Link / Control-A1 controller. Flash a board connected to this computer's USB port straight from the browser: the page recognises the chip and writes the matching firmware. Demo of the web portal · Project on GitHub

This browser cannot do it. Flashing needs Web Serial: use Chrome, Edge or Opera on a computer (or Chrome on Android with a USB OTG cable). Firefox and Safari do not have it. You can still download the images below and write them with esptool.
Your browser does not support Web Serial (use Chrome, Edge or Opera). This page must be opened over HTTPS.

How it works

  1. Plug the board into a USB port of this computer and press Connect and install.
  2. Choose the serial port in the browser window (an USB JTAG/serial or USB Serial device). The page reads the chip type and picks the firmware for it.
  3. Confirm. The image is written at address 0x0 (bootloader, partition table and application). Leave Erase device off to keep the settings of a board that already runs this firmware (WiFi, stations, titles); turn it on for a clean start.
  4. When it ends the board restarts. The Logs & Console button shows its output.

If the board is not listed, put it in download mode: hold BOOT while plugging it in (or while pressing RESET), then try again. The boards with a native USB port need no driver on current Windows, macOS and Linux.

After the first installation

Boards with WiFi: open the serial console (Logs & Console, or any terminal) and type WIFI "NetworkName" "password" then WEB ON; NET shows the address, and the portal opens at http://slink.local/. The next updates can be done over WiFi from the portal (Settings › Firmware update), without the cable. The wiring to the amplifier is described in the wiring guide.

The firmware is flashed with ESP Web Tools (Apache-2.0). The images are the ones of the latest release, copied here when the site is built (checksums in SHA256SUMS.txt of the release).
