Install the S-Link firmware

ESP32 Sony S-Link / Control-A1 controller. Flash a board connected to this computer's USB port straight from the browser. Demo of the web portal · Project on GitHub

This browser cannot do it. Flashing needs Web Serial: use Chrome, Edge or Opera on a computer (or Chrome on Android with a USB OTG cable). Firefox and Safari do not have it. You can still download the images below and write them with esptool.

1 · Recognise the board (optional, nothing is written)

Connect the board, then press Detect hardware: the page opens the serial port, asks the chip who it is and shows what it found. The firmware that fits is selected below. The board restarts when the check ends.

2 · Choose the firmware

Looking up the release…
A factory image (bootloader + partition table + application in one file, like slink-esp32s3-factory.bin or the out/ folder made by tools/ci_build.sh).

3 · Install

Your browser does not support Web Serial (use Chrome, Edge or Opera). This page must be opened over HTTPS.

The image is written at address 0x0. Leave Erase device off to keep the settings of a board that already runs this firmware (WiFi, stations, titles); turn it on for a clean start. If the board is not listed, hold BOOT while plugging it in (or while pressing RESET) and try again. Boards with a native USB port need no driver on current Windows, macOS and Linux. The Logs & Console button shows the output of the board after the installation.

Where the images come from: a browser cannot download the files of a GitHub release directly (GitHub does not allow it from another site), so when this site is built the workflow copies the factory images of the latest release into firmware/ and checks them against its SHA256SUMS.txt. Verify against GitHub repeats the check in your browser: it computes the SHA-256 of the copy and compares it with the digest GitHub reports for the release file, live.

After the first installation, boards with WiFi: open the serial console and type WIFI "NetworkName" "password" then WEB ON; NET shows the address and the portal opens at http://slink.local/. Later updates can be done over WiFi from the portal (Settings › Firmware update). Wiring: wiring guide. Flashing uses ESP Web Tools and esptool-js (Apache-2.0).
