# Web interface coverage of the S-Link protocol

> Generated by `tools/gen_coverage.py` from the command catalogue in `main/web/index.html` (the same table drives the *Documented commands* panel of the Console tab). Do not edit by hand.

What was compared: the command tables published at [hifi-remote.com](https://www.hifi-remote.com/sony/Sony_dsp.htm) (pages 192 amplifier, 193 tuner, 195 sound field/EQ, 144 CD player), [boehmel.de/slink.htm](https://www.boehmel.de/slink.htm) (MD, amplifier, tuner, surround), [Ircama/Sony_SLink](https://github.com/Ircama/Sony_SLink) and the Control-A1 reverse-engineering notes listed in `docs/en/CODES_TO_TRY.md`; the commands of the firmware command line (`main/cli.c`); and the replies decoded by the firmware (`main/decode.c`).

- **Every documented command can be sent from the web interface** (*Console › Documented commands*: parameter widgets, a live frame preview, filter; destructive or audible ones, and those for units not on the bus, ask for confirmation). 48 of them also have a dedicated control in the main tabs.
- **Every command of the firmware command line** is reachable: see the table further down (two groups of pin-test/terminal commands are console-only on purpose).
- **Every S-Link reply is decoded and shown** in the Console. The replies that carry state are also used by the interface (table at the end).
- The “verified” column is what was measured on a real STR-DA50ES; the others are from the documentation and may behave differently on other models (`C0 83` input type, for instance, is `0..4` on hifi-remote and `1/2/4` on boehmel).
