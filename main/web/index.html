Soglia di ascolto

Il motore della manopola dell'amplificatore non comunica la posizione: la stima del volume si basa su questi numeri. Salvati nel dispositivo.

Backup e ripristino

Salva in un file la configurazione completa: quella dell'amplificatore (nomi degli ingressi, campo sonoro, equalizzatore, livelli, altoparlanti), quella che resta nel dispositivo (impostazioni, rete, MQTT, stazioni e preferiti radio) e le preferenze di questa interfaccia. Il file si può poi ripristinare.

Includi le passwordPassword WiFi e MQTT nel file, in chiaro: conserva il file con cura
