Controllo via Bluetooth

Questa pagina controlla il tuo dispositivo S-Link direttamente via Bluetooth LE, senza WiFi e senza il portale web del dispositivo. Serve soprattutto per l’ESP32-H2, che non ha il WiFi, e per ogni scheda con il BLE acceso (comando BLE ON).

  • Servono Chrome, Edge o Opera (PC o Android): Firefox e Safari non supportano Web Bluetooth.
  • Il dispositivo deve essere acceso, con il BLE attivo, e non collegato ad altre app.
  • Senza password Bluetooth (comando BLEPASS) non c’è autenticazione: chiunque sia nel raggio può collegarsi con un’app qualsiasi. Tieni il BLE acceso solo quando serve.

Soglia di ascolto

Il motore della manopola dell'amplificatore non comunica la posizione: la stima del volume si basa su questi numeri. Salvati nel dispositivo.

Aggiornamento del firmware

Consenti l'invio dall'esterno (push)Spento per impostazione predefinita: finché è spento nessuno può inviare un firmware al dispositivo dalla rete. Accendilo solo mentre usi «Invia un file» o tools/ota_push.py.
Consenti il download da internet (pull)Il dispositivo scarica un firmware solo quando lo chiedi tu («Cerca e installa» o il comando OTA UPDATE), mai da solo.

Aggiorna da internet

Il dispositivo scarica da solo il file e si riavvia. Sorgente predefinita: l'ultima release su GitHub.

Invia un file dal computer

Scegli il file .bin del firmware per questo chip (slink-<chip>.bin): viene scritto nell'altro slot e il dispositivo si riavvia. Da un computer si può anche usare tools/ota_push.py.

Protezione dell'invio

Password facoltativa per l'invio del firmware (dal portale o con tools/ota_push.py). Senza password chiunque nella rete locale può caricare un firmware.

Se il nuovo firmware non si conferma entro 30 secondi dall'avvio (o si blocca), il dispositivo torna da solo a quello precedente.

Backup e ripristino

Salva in un file la configurazione completa: quella dell'amplificatore (nomi degli ingressi, campo sonoro, equalizzatore, livelli, altoparlanti), quella che resta nel dispositivo (impostazioni, rete, MQTT, stazioni e preferiti radio) e le preferenze di questa interfaccia. Il file si può poi ripristinare.

Includi le passwordPassword WiFi e MQTT nel file, in chiaro: conserva il file con cura
